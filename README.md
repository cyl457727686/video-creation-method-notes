# 视频创作方法笔记

[简体中文](README.md) · [English](README_EN.md)

### MiniMax H3 · Seedance 2.5 · Seedance 2.0

从公开视频、作者提示词和制作过程里，整理可用于分镜、提示词编写与实片复盘的工作经验。

**发布版本：V006｜方法研究：V005｜更新：2026-11-03｜支持 Agent Skill 与 Markdown 使用**

这套笔记关注一个具体问题：如何把“有电影感、动作自然、画风统一”这类笼统目标，写成可观察、可检查的画面和声音安排。

## 安装 Skill

支持 Agent Skills 的 AI 工具可以安装 `video-creation-methods`，由统一入口按 H3、Seedance 2.5 或 Seedance 2.0 加载对应参考。普通聊天网页是否支持安装，取决于产品本身；不支持时仍可上传对应 Markdown 使用。

### 通过安装工具

安装 [Node.js](https://nodejs.org/) 22.20 或更新版本后，在自己的项目目录打开终端运行：

```bash
npx skills add cyl457727686/video-creation-method-notes --skill video-creation-methods
```

按安装工具提示选择自己的 AI 编程助手。该命令使用第三方 [Vercel Skills CLI](https://github.com/vercel-labs/skills)，不同助手的路径和调用方式由安装工具处理，不是视频模型API。

### 手动安装

从最新 Release 下载 Skill ZIP，解压后将完整的 `video-creation-methods` 文件夹放入你的 AI 工具支持的技能目录；保留其中的 `references` 和 `agents`。具体目录以该工具说明为准。重新加载工具后确认技能出现。

### 第一次调用

支持 `$技能名` 的助手中可以输入：

```text
$video-creation-methods
我用 Seedance 2.0，想做一个动画镜头：[填写剧情]。
参考素材：[附图或说明]。台词：[原文]。
请结合这些方法检查动作、空间、运镜和声音，输出适合该模型的提示词。
```

其他助手使用其技能菜单或调用方式。AI需要知道你选择的模型和实际素材，技能不会自动接入视频生成服务。

## 可以帮助你处理什么

- **参考素材互相矛盾**：先核人物、空间、道具阶段，再决定哪些属性需要保留。
- **动作含糊或接触错位**：区分入态、建立接触、受力变化和可见结果。
- **运镜只有术语，没有目的**：写清起幅、路径、落幅，以及最终要让观众看到的信息。
- **动画画面好看但不好读**：安排明暗与边缘层次、前中后景、关键姿态和运动主次。
- **声音与画面各说各话**：区分发声者、听者、同步事件、环境底声和观众配乐。
- **不知道该改提示还是改剪辑**：分开检查作者意图、原输入、生成素材、后期取舍与最终效果。

动画经验适用于不同题材与画风。哑光块面、雾层、特定景别等属于按作品选择的做法，不是所有动画的统一标准。

## 如何使用

1. 选择与你当前模型对应的文档，并打开其中链接的官方指南。
2. 提供当前镜头任务、有效参考素材、原文台词与实际生成入口。
3. 从方法中选取与本镜问题有关的条目，再按模型自身格式编写。
4. 用真实输出检查动作、声音、连续性和剪辑采用区间；记录实际改善与仍未解决的问题。

可以把对应 Markdown 文件作为 AI 助手的参考上下文，搭配下面这段请求：

```text
请参考我提供的模型对应方法文档，处理当前镜头。
先检查参考素材、动作入态、人物与空间关系，再按本镜任务选择适用方法。
区分官方规则、案例观察和未经验证的推论，不把案例画风、人物或道具带入我的作品。
最终输出采用当前模型的官方格式；缺少必要输入时明确指出，不编造素材编号或能力。
```

这段话适用于手动上传文档的方式，是给助手的工作请求，不是直接提交给视频模型的提示词。安装型 Skill 与手动文档共用同一套方法；两者都不会自动接入模型、下载素材或发起付费生成。

## 当前成熟度

这是依据来源整理的研究方法补充。“增强版”指文档内容对创作方法的补充，不表示训练或微调了模型。

已登记的主体视觉内容和声音方法研究完成整理；部分观察使用截图、源帧缩图和音频模型，不能据此声称连续视听、每个细节或口型全部通过。三版尚无目标模型对照生成数据，不承诺成功率、质量提升或成本节省。完整边界与已发现的纠错类型见 [LIMITS.md](LIMITS.md)。

本包不是官方项目，不替代官方文档。原研究项目的英文正文、素材批准和后期配音选择会明确标为项目约定，不自动成为读者的工作流。
